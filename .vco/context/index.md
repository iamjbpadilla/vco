# VCO Project Context

Start here if you are an agent entering this repository.

## Must-read files, in order

1. `AGENTS.md` — the Agent Constitution; this is binding.
2. `PROJECT_STATE.md` — current state of the VCO repository.
3. `SCOPE.md` — what is in and out of scope for VCO 0.1.
4. `REQUIREMENTS.md` — the VCO 0.1 requirements and their status.
5. `TASKS.md` — what is being done now and what remains.
